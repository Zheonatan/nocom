Install

  1. macOS Homebrew (recommended)
    brew tap Zheonatan/tap
    brew trust --cask Zheonatan/tap/nocom
    brew install --cask nocom

    Or download the .dmg: Apple Silicon · Intel.

    Before you open it the first time: note 1.

  2. Windows winget (recommended)
    winget install Zheonatan.NoCom

    Or download the .exe. Through winget there is no warning at all.

    Before you open it the first time: note 1.

  3. Linux direct package
    sudo dpkg -i NoCom_0.3.0_amd64.deb

    Download it first: .deb · .rpm · AppImage.

Notes

  1. note 1

    First launch

    “NoCom” is damaged and can't be opened. You should move it to the Trash. what macOS shows

    Click Cancel — never “Move to Trash”. The app is not damaged: it is not signed by Apple yet. To clear the flag:

    xattr -dr com.apple.quarantine "/Applications/NoCom.app"

    Installing through Homebrew, repeat after every brew upgrade.

    Windows protected your PC. what SmartScreen shows

    Click More info and then Run anyway. The installer is not signed yet; through winget the warning never appears.

    On Linux there is no system warning: the package installs and the app opens straight away.

  2. note 2

    What it is not

    Not a project manager: no due dates, priorities, subtasks, labels or collaboration. It is a list, and that is all.

  3. note 3

    Where your tasks live

    In a todos.json file on your machine. To delete everything, delete the file.
