Instalar

  1. macOS Homebrew (recomendado)
    brew tap Zheonatan/tap
    brew trust --cask Zheonatan/tap/nocom
    brew install --cask nocom

    Ou baixe o .dmg: Apple Silicon · Intel.

    Antes da primeira abertura: nota 1.

  2. Windows winget (recomendado)
    winget install Zheonatan.NoCom

    Ou baixe o .exe. Pelo winget não aparece aviso nenhum.

    Antes da primeira abertura: nota 1.

  3. Linux pacote direto
    sudo dpkg -i NoCom_0.3.0_amd64.deb

    Baixe primeiro: .deb · .rpm · AppImage.

Notas

  1. nota 1

    Primeira abertura

    “NoCom” está danificado e não pode ser aberto. Você deve movê-lo para o Lixo. o que o macOS mostra

    Clique em Cancelar — nunca em “Mover para o Lixo”. O app não está danificado: ele ainda não é assinado pela Apple. Para liberar:

    xattr -dr com.apple.quarantine "/Applications/NoCom.app"

    Instalando pelo Homebrew, repita a cada brew upgrade.

    O Windows protegeu seu PC. o que o SmartScreen mostra

    Clique em Mais informações e depois em Executar assim mesmo. O instalador ainda não é assinado; pelo winget o aviso não aparece.

    No Linux não há aviso de sistema: o pacote instala e o app abre direto.

  2. nota 2

    O que ele não é

    Não é gerenciador de projetos: sem prazos, prioridades, subtarefas, etiquetas ou colaboração. É uma lista, e só.

  3. nota 3

    Onde ficam as suas tarefas

    Num arquivo todos.json no seu computador. Para apagar tudo, apague o arquivo.
